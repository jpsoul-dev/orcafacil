# Funcionalidades do App

Este documento lista novas features e melhorias esperadas para o app.

## Novas Features

### Criar recibos avulsos

- Atualmente consigo criar recibos apenas para orçamentos com status de "finalizado". Mas quero espandir a funcionalidade para permitir criar recibo avulso, ou seja, sem estar vinculado a um orçamento.
- A criação de recibos avulsos é ligeiramente diferente pois quero poder incluir os itens no recibo com seus valores (assim como é feito no orçamento). 
- O recibo deve seguir o mesmo layout de recibo já existente para recibos de orçamentos.
- também poder listar os recibos  

### configurações de orçamento

- quero poder configurar alguns campos para mostrar/ocultar no orçamento, por exemplo para mostrar ou não o número do orçamento na visualização.

### Desconto por item no orçamento

- poder adicionar desconto em cada item no cadastro de orçamento. Atualmetne consigo apenas dar um desconto sobre o total, ainda quero manter esse junto com o desconto em cada item.
